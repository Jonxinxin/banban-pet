# 伴伴 1.0.0 初版验收记录

验证日期：2026-09-28。环境：Windows 10 专业版 22H2（10.0.19045），Intel i5-12600KF，16 个逻辑处理器，系统显示缩放 125%。

## 结果

已构建可独立运行的 Windows x64 安装包，并在当前账户下完成静默安装（退出码 0），安装目录为 `%LOCALAPPDATA%\Programs\Banban`。安装后的正式可执行程序已通过启动、离线资源加载、礼物包往返和原生检测组件验证。

| 检查组 | 结果 | 覆盖内容 |
| --- | --- | --- |
| 核心行为测试 | 15 / 15 通过 | 周期提醒、合并、延后、时段边界、抑制恢复、时钟变化、情话去重与限额、礼物校验、原子保存及备份 |
| 应用 UI 自动化 | 10 个流程通过，无渲染错误 | 首次引导、无焦点桌宠、自动保存、编辑情话、提醒预览、真实调度事件、暂停、礼物导入、外观与隐藏、隔离及断网约束、重启持久化 |
| Windows 原生集成 | 6 项通过 | 本地检测器就绪、独立进程实际全屏时隐藏、退出全屏恢复、长文案边界、关闭窗口前保存、设置关闭后桌宠继续运行 |
| 正式安装版 | 5 项通过 | 正式 exe 启动、礼物导出预览再导入、非法文件不破坏配置、删除私人内容同时清理备份、打包后的原生组件启动 |

UI 自动化直接驱动 Electron 窗口。全屏检查启动了一个独立进程的真实全屏窗口，不只依赖模拟状态。锁屏与休眠恢复以注入对应系统事件状态验证，没有实际锁定用户桌面。

## 性能采样

- 安装版一次启动至首次引导可见约 **0.51 秒**。这是当前机器的单次启动测量，文件缓存可能已预热，不代表所有设备的冷启动时间。
- 关闭设置约 20 秒后，Electron 各进程私有内存合计约 **119.8 MiB**，全屏检测组件约 **11.6 MiB**，总计约 **131 MiB**。
- 上述是私有提交内存采样，不等同于任务管理器的单个进程工作集；共享页统计方式不同会造成数字差异。
- 开发态短时 CPU 采样约 0.82%（Electron 返回的各进程百分比合计），仅供观察。尚未完成 PRD 要求的连续 10 分钟正式资源基准，也未完成 8 小时稳定性验收。
- 为控制内存，采用软件渲染和间歇待机动作；关闭设置会销毁其窗口及渲染进程。

## 已知限制与尚待实机确认

1. 当前验证机器为 Windows 10；Windows 11、她的实际电脑、物理双屏插拔和不同显示器 DPI 尚未完成实机验证。
2. UI 测试包含 100% / 125% / 150% / 200% 的网页缩放可见性检查，这不等同于所有 Windows DPI 环境测试。
3. Computer Use 工具在恢复重试后仍报 `native pipe is unavailable`，因此未完成该工具下的真实鼠标拖动、透明区域穿透及托盘菜单人工式点击检查。相关交互已实现，应用级状态、窗口可见性与焦点属性已验证。
4. 全屏检测按窗口边界和窗口样式判断。无法据此识别所有屏幕共享、特殊游戏和会议状态，保留手动暂停入口。
5. 安装包尚未商业代码签名。构建工具中的“signing”输出不代表已经存在可信证书，文件签名检查结果为 `NotSigned`。
6. 安装已实际完成；Windows 卸载流程及“卸载时清除数据”的交互分支已编译并检查，尚未通过系统 UI 完整走查。应用内的私人内容与备份清除已验证。
7. 首版暂不包含自动更新、macOS、跨设备同步、AI 对话或实时远程传话。
