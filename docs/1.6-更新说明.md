# 伴伴 1.6 · 认真看着你的鼠标

把单独移动眼睛升级为一整套注视动作：

- 眼睛先追上鼠标，头部随后轻轻转向、抬起或低下，身体再小幅倾向同一方向。
- 脸部随着转头产生轻微位移，让五官与头部轮廓有层次；鼠标靠近脸时，桌宠会稍稍凑近。
- 转头、呼吸和待机动作进行时，眼睛继续修正方向，保持看向鼠标的位置。鼠标停住后仍保持注视，不会自行回正。
- 鼠标持续移动时，暂缓新的随机歪头、抬爪和伸懒腰等待机动作；停下后再恢复。已经开始的动作自然做完。

所有动作都有幅度限制，并使用不同速度的缓动。头部方向以固定坐标为基准，避免因自己的移动反复追逐、抖动。鼠标停稳后降低刷新频率，仍会随呼吸校正视线；隐藏或系统减少动画时停止。

猫和狗、三档尺寸均支持。气泡期间也会跟随，拖动时暂时回正，松开后恢复。抱抱、花束、情绪小伞和五连击爱心保留。

安装程序：`release/Banban-Setup-1.6.0.exe`。直接运行版：`release/win-unpacked/伴伴.exe`。已送出的独立桌宠需要在新版里重新制作。

验证覆盖不同方向与距离、眼头身体的响应顺序、动作边界、持续移动时的注视优先级，以及真实 Windows 鼠标坐标下的跟随。
