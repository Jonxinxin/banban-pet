# 伴伴，使用小纸条

## 第一次见面

1. 在 Windows 10 / 11 的 64 位电脑上运行 `Banban-Setup-1.0.0.exe`，按提示安装。
2. 打开伴伴，如果收到了礼物包，先点“打开专属礼物”，选择 `.banban.json` 文件，查看内容后收下。
3. 在“温柔提醒”中确认提醒间隔与有效时段；需要时在“专属心意”修改称呼。
4. 回到“伴伴的家”，点击“开始陪伴”。桌宠会出现在桌面右下角。

安装后不需要安装 Node.js、运行开发命令或保持联网。开机启动默认关闭，可以到“通用设置”主动开启。

## 和桌宠相处

| 操作 | 会发生什么 |
| --- | --- |
| 单击桌宠 | 摸摸互动与一句回应 |
| 拖动桌宠 | 移动位置，松开后记住 |
| 右键桌宠 | 打开情话、暂停、设置、退出等菜单 |
| 双击系统托盘的桌宠图标 | 找回桌宠，回到屏幕右下角 |
| “来句情话” | 主动收到一句，不受每日自动次数限制 |
| 关闭设置窗口 | 设置保存，桌宠继续在桌角陪伴 |
| 菜单“退出伴伴” | 完全退出，停止后台提醒 |

Windows 可能把托盘图标折叠到任务栏的小箭头里；找不到桌宠时先看那里。

## 提醒怎样工作

- 默认喝水每 60 分钟、起身每 90 分钟。
- 默认每天 09:00–12:00、14:00–18:00 自动提醒，其余时间只保留桌宠与主动互动。
- 刚打开应用、进入有效时段、恢复暂停或从锁屏唤醒时，都重新等待一个完整间隔。
- 同时到期的两类提醒会合并；任意两次自动气泡至少间隔 10 分钟。
- 点击“喝过啦 / 活动过啦”会得到桌宠的回应；“这次跳过”或不点击都不会被催促。
- “10 分钟后”仅延后一次；延后提醒不会再出现同一个延后按钮。
- 普通提醒约 12 秒后收起。鼠标移到气泡上会暂停消失，长文案可以滚动查看。

例如：下午 14:20 打开伴伴，喝水间隔是 60 分钟，那么第一次喝水提醒是 15:20，而非 15:00。若现在已离开有效时段，桌宠保持安静是正常现象。

## 想专心或休息

- 可以暂停 30 分钟、1 小时，或直到明天首个有效时段。
- 暂停期间桌宠仍然在，自动提醒与自动情话停止；主动互动仍可使用。
- 隐藏桌宠会同时停止自动气泡。恢复显示后重新开始计时。
- 全屏应用会触发自动隐藏，退出全屏后恢复；错过的提醒不会堆积补发。
- 全屏识别不等同于会议识别。分享屏幕、投影或重要会议前，用手动暂停最直接。

## 把它变成一份专属礼物

1. 打开“专属心意”，填写她的昵称、你的称呼和欢迎语。
2. 点击“写一句”，加入你们的日常、想说的话或只有你们懂的梗。
3. 可以使用 `{昵称}`、`{我的称呼}`，显示时会替换为对应称呼。未填写时用“亲爱的”和“我”。
4. 不想混入通用内容，可以关闭“也使用伴伴准备的温柔文案”。
5. 点击“导出礼物”，保存配置文件。把安装包与这个文件一起交给她。

礼物包仅包含称呼、欢迎语和自定义文案，不包含你的电脑路径、提醒记录或设置。导入需要确认，会替换现有的专属内容，保留她的提醒设置。她可以编辑或删除全部内容。

附带的示例礼物包可以直接导入，也可以在应用里改成你自己的版本；里面没有预设真实姓名。

## 常见情况

**为什么还没提醒？**

查看“温柔提醒”页显示的状态与下次时间。非有效时段、暂停、隐藏、全屏时均不自动弹出。修改间隔后也会重新计时。

**情话怎么不出现？**

自动情话随机间隔 2～3 小时，每天最多 2 次，并遵守有效时段。没有可用文案时会暂停自动情话。想立即看到，可以点“来句情话”。

**桌宠不见了？**

先退出全屏，再双击托盘图标，或打开“桌宠模样 → 带它回家”。也可以再次启动伴伴，打开已有实例的设置。

**安装时提示发布者未知？**

当前私人初版尚未购买商业代码签名证书。请确认文件来自这次交付，不需要关闭 Windows 防护。若电脑策略禁止运行未签名软件，应使用符合该电脑策略的签名版本。

**如何卸载与删除私人内容？**

在 Windows“应用和功能”中卸载“伴伴”，卸载时可以选择清除本机数据。也可以先在应用的“通用设置”中清除专属内容。已经导出到其他位置的礼物包需要自行管理。


## 1.2 新增：大白狗与专属摸摸回应

在制作端的“桌宠模样”选择“云朵大白狗”，立即切换；奶油小猫仍可选择。每个形象有 40 句点击回应（32 句通用、8 句形象专属），最近 8 句不重复，重启也会记住。

在“专属心意”填写“她的昵称”和“你的称呼”，回应会自动带上称呼。未填昵称时使用“亲爱的”。“摸摸试试看”可在桌面预览。

选择完成后，从“送给她”重新制作独立 EXE。她收到后直接显示你选好的形象，不需要配置。已经发出的旧 EXE 不会自动更新。
