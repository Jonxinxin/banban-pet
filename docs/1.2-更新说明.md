# 伴伴 1.2 · 云朵大白狗

## 新增形象

“桌宠模样”中可选择 **奶油小猫** 或 **云朵大白狗**，点击立即切换并自动保存。大白狗有蓬松白毛、浅绿色围巾与摇尾巴动作，支持摸摸、喝水、伸懒腰和爱心反馈。托盘图标与制作端预览随选择更新。

## 更丰富的摸摸回应

点击回应由原来的 3 句扩展为每个形象 **40 句**：32 句共用、8 句形象专属，共 48 条文案。最近 8 句不会重复，退出重开也会记住。

在“专属心意”填写“她的昵称”和“你的称呼”，回应会自然带上称呼。没有填写昵称时使用“亲爱的”。例如：

- 小朋友，尾巴摇得这么快，是因为见到你啦。
- 替大朋友送来一个抱抱，小朋友，请签收。
- 小朋友，摸摸可以续杯，陪伴也是。

“桌宠模样”新增“摸摸试试看”，可直接查看桌面气泡效果。大白狗使用专属的摇尾巴气泡标题；内置情话里提到小猫的地方也会随形象调整。你自己写的情话保持原文。

## 送给她

选好形象、称呼和提醒时间，再到“送给她”制作独立 EXE。大白狗版本使用大白狗文件图标。她双击后直接看到准备好的桌宠，无需填写配置；仍可暂停、隐藏、退出。

旧设置升级后保留原来的小猫与所有个人内容。已经发出的 EXE 不会自动更新，需要重新制作并发送新版。

## 验证

- 23 项核心测试：旧配置兼容、形象导出、昵称替换、近期文案去重、重启记忆、内置情话适配等。
- Electron 界面测试：即时切换、昵称气泡无滚动条、形象动作、重启保留选择、原有提醒与保存流程。
- 正式构建回归：原生拖动、自适应气泡、独立 EXE 提取与启动、接收端形象和设置隔离。

测试记录位于项目 `test-results/smoke-report.json` 和 `test-results/revision-report.json`。
