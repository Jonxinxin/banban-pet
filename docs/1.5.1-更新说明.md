# 伴伴 1.5.1 · 看着你说话

修复欢迎语、情话或提醒气泡出现时眼睛停止跟随的问题。待机动作的暂停与视线跟随分开处理；气泡停留期间，眼睛也会继续看向鼠标。摸摸后的眯眼笑保持约 1.6 秒，然后重新睁眼，文字仍可继续阅读。

四种待机动作继续保留。拖动时视线暂时回正，松开后恢复；隐藏或系统减少动画偏好仍会暂停。

本版恢复常用发布路径：安装程序为 `release/Banban-Setup-1.5.1.exe`，直接运行版为 `release/win-unpacked/伴伴.exe`。1.5.0 曾构建在单独目录，原来的已安装程序和解压目录可能仍是旧版；更新时请确认使用 1.5.1。

增加真实系统验证 `npm run test:gaze-live`：直接读取 Windows 鼠标位置，不替换坐标源或动画偏好，确认两种桌宠在情话、提醒气泡期间都能移动眼睛，并检查待机动作自动出现。
