# 伴伴 1.4.1 · 让陪伴更简单

夸夸扭蛋与“抱抱我”、日常情话的用途重叠，本版移除扭蛋功能。右键菜单、首页摘要和“藏起来的惊喜”设置页同步精简，扭蛋机画面、夸夸文案及小心意券编辑、随机抽取和历史记录逻辑一并移除。

“藏起来的惊喜”保留三项：

| 小惊喜 | 使用方式 |
| --- | --- |
| 长按抱抱 | 按住桌宠 2 秒，或右键“抱抱我”；可以再抱一下。 |
| 纪念日花束 | 纪念日当天第一次摸摸收到花束和信，也可右键重看。 |
| 情绪小伞 | 右键“今天有点累”，可以再抱一下或安静陪伴 30 分钟。 |

奶油小猫、大白狗、日常情话、喝水和活动提醒、五连击满屏爱心继续可用。

旧设置和旧礼物配置仍可读取；载入时忽略已移除的扭蛋字段和抽取历史，保留称呼、其他提醒、彩蛋设置及纪念日记录。旧扭蛋文案和小心意券不再展示，也不包含在新制作的礼物中。

安装 `release/Banban-Setup-1.4.1.exe` 更新制作端。已发出的独立桌宠 EXE 不会自动更新，需要在新版“送给她”中重新制作。
