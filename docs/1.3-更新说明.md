# 伴伴 1.3 · 藏不住的喜欢

## 已实现：五连击爱心彩蛋

在桌宠身上 **3 秒内连续点击 5 下**（相邻两下不要间隔超过 0.9 秒），就能发现藏起来的小惊喜。奶油小猫和云朵大白狗都支持。

爱心从桌宠所在的位置飞向屏幕中央，汇成一颗玫瑰金色的大心。满屏漂浮的小爱心、柔和星光与玫瑰色背景陪着告白出现：

> 只给「她的昵称」的小惊喜  
> 全世界的心动，  
> 这一刻都奔向你。  
> ——「你的称呼」，一直偏爱你

末尾爱心轻轻散落，整场约 10 秒后淡出。动画覆盖桌宠所在的整块屏幕；多显示器时使用桌宠当前所在屏幕。

- 你的昵称与署名仍在制作端“专属心意”填写，接收端直接使用已配置的内容。
- 点击右上角“收好心意”可立即关闭；成功注册临时 Esc 快捷键时也可按 Esc 关闭。
- 拖动、长按、打开右键菜单、隐藏、锁屏会打断连续点击，预览文案按钮不会触发彩蛋。
- 触发后有 12 秒间隔，连续猛点不会叠加动画；播放时自动气泡暂停展示。
- 全程静音，不主动抢占输入焦点，隐藏、锁屏、进入其他应用全屏或退出应用会收起动画。
- 尊重系统的减少动态效果偏好，改为较安静的心形画面。

升级保留已有形象、昵称、情话和提醒设置。给她的独立 EXE 需要重新制作，旧文件不会自动更新。

## 验证范围

核心测试覆盖点击阈值、间隔、冷却；Electron 事件测试覆盖实际桌宠事件处理、接收端、两种形象、昵称文本、自适应屏幕范围、不抢焦点、自动退场、关闭按钮、隐藏与锁屏收起。另检查了原有提醒、形象切换与保存流程。

当前自动化环境没有可用的 Windows 输入桌面，系统级真实鼠标注入与 Esc 按键验证未能运行。可在有交互桌面的 Windows 环境运行 `npm run test:surprise:native` 补验；测试脚本会明确报告无法注入的情况。

更多彩蛋建议见 [彩蛋灵感](彩蛋灵感.md)，这些是候选设计，尚未启用。
