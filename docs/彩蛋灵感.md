# 给她藏几份小惊喜

当前已实现长按抱抱、纪念日花束与情绪小伞，使用方式以 [1.4.1 更新说明](1.4.1-更新说明.md) 为准。夸夸扭蛋因与抱抱、日常情话用途重复已移除。下面保留其他设计灵感；专属暗号与晚安小窝仍是候选设计。

| 彩蛋 | 怎么发现 | 她会收到什么 |
| --- | --- | --- |
| 长按抱抱 | 按住桌宠 2 秒，不拖动 | 大白狗张开爪爪、慢慢靠近，轻轻抱住一颗写着她昵称的心。“小朋友，抱一会儿再去忙吧。今天辛苦啦。”松手后留下一颗小心，稍后消失。 |
| 纪念日花束 | 你预先填好纪念日，当天第一次摸摸它 | 桌宠从背后拿出花束，出现“和小朋友相遇的第 520 天”。再点花束，打开你提前写好的那封信。生日则换成小蛋糕和蜡烛。 |
| 只属于你们的暗号 | 在桌宠的“小纸条”入口输入约定暗号 | 输入你们第一次约会的地点、她常说的口头禅或专属暗号，解锁对应的一句话、小插画或约会邀请。只处理这个输入框里的内容。 |
| 晚安小窝 | 晚上 22:30 后，第一次摸摸桌宠 | 大白狗抱着枕头钻进小毯子，冒出一颗月亮：“小朋友，世界可以明天再拯救，今晚先做个好梦。”每天一次，不反复催睡。 |
| 雨天的小伞 | 她点“小纸条”里的“今天有点累” | 桌宠撑开小伞，接住几滴画出来的小雨，再递一朵小花：“小朋友，今天不用表现得很好，我喜欢的本来就是你。”可选择“再抱一下”或“安静陪我”。 |

称呼、日期、暗号、信件和特别文案都在你这边准备好，随接收版一起带过去。
