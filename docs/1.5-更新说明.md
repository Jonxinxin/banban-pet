# 伴伴 1.5 · 会看着你，也会自己动一动

奶油小猫和云朵大白狗现在都会平滑地看向鼠标，鼠标移到桌宠窗口外也能跟随。视线有自然的活动范围，快速换方向时缓缓转过去；眨眼和瞳孔移动分开处理，眨眼不会让视线跳回正中。

新增四种自动待机动作：

| 动作 | 表现 |
| --- | --- |
| 歪头 | 轻轻歪头、停一下，再回正；大白狗的耳朵跟着摆动。 |
| 抬爪 | 抬起一只前爪，摇两下打招呼。 |
| 伸懒腰 | 先微微蹲下，再舒展身体和小爪子。 |
| 甩尾巴 | 小猫慢慢甩尾巴，大白狗摇得更欢快。 |

这些动作随机错开播放，一轮内不重复，同一个动作也不会连续两次出现。平时保留轻微呼吸、不等间隔的眨眼和偶尔的双眨眼。拖动、摸摸、提醒和抱抱优先，待机动作会让开，互动结束后再恢复。

鼠标坐标只用于实时绘制，不保存、不联网。主进程每秒最多采样 30 次，位置没有变化时不发送重复消息；画面按显示器刷新节奏补间，视线到位后停止逐帧计算。隐藏、锁屏或休眠时停止采样和待机计时；尊重系统“减少动画”偏好。

两种桌宠、三档尺寸都支持以上效果。更新制作端使用 `release/1.5.0/Banban-Setup-1.5.0.exe`。已发出的独立桌宠不会自动更新，需要在新版“送给她”中重新制作。

验证入口：`npm test`、`npm run test:motion`、`npm run test:moments`、`npm run test:ui`。动作测试覆盖视线方向与边界、不同刷新率的缓动、眨眼并行、猫狗三档尺寸、动作画面、交互优先级和隐藏恢复。
