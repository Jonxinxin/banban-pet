# 伴伴 1.1：消息、拖动与交付方式调整

## 这次修复

1. **消息气泡不再出现滚动条。** 气泡改成独立窗口，按内容自动确定高度。小猫靠近屏幕顶部时，气泡可以放到下方或侧面。超长文字分段展示、自动继续，也可以点“下一句”，保留完整内容。
2. **重做拖动。** 桌宠窗口仅包住猫咪，不再为上方气泡预留 440 像素的整体窗口。Windows 原生组件直接以物理像素跟踪鼠标和移动窗口，每次从按下时的位置计算，避免页面事件往返、混合坐标与逐帧累加。只限制猫咪本身的屏幕边界。
3. **你制作，她直接使用。** 制作端新增“送给她”，可把当前称呼、欢迎语、全部文案及其开关、提醒间隔、有效时段、尺寸和置顶状态生成到一个独立 EXE。接收端没有首次配置、文件导入和设置中心，双击即可出现桌宠。

## 怎样交给她

你使用桌面上已经安装的“伴伴”，调整好“温柔提醒”“专属心意”“桌宠模样”，然后打开“送给她”，点击“制作送给她的桌宠 .exe”。把生成的这一个 EXE 发给她。

她双击收到的文件即可使用。第一次启动会在本机安顿运行文件，可能等几秒；以后再次打开直接启动。不需要安装 Node.js、不需要另外下载依赖、不需要手工导入配置，也不联网。

接收端保留来句情话、暂停、显示 / 隐藏、找回桌宠和退出，不展示制作端设置。你这边的暂停、隐藏、位置和使用历史不带过去；不会替她自动开启开机启动。

以后修改内容，在你的制作端重新生成一份即可。她先退出旧桌宠，再打开新的文件。不同导出文件有独立身份，互不覆盖个人运行状态；这不是远程更新功能。

## 数据位置

- 制作端：`%APPDATA%\Banban`，原有已保存配置继续保留。
- 接收端运行文件：`%LOCALAPPDATA%\BanbanGifts\<礼物 ID>`。
- 接收端状态：`%APPDATA%\BanbanGifts\<礼物 ID>`。

礼物 EXE 包含你写入的内容，是接收者可以读取的本地文件；不要放入密码等无关信息。删除下载的 EXE 不会自动清除第一次启动解包的运行文件。需要移除时，先退出这只桌宠，再删除上述对应礼物目录。
