# 伴伴 · Windows 电子桌宠

当前版本 **1.6.0**。猫和狗会用眼睛、头部和身体一起追随鼠标：眼睛先看过去，头和身体轻轻跟上，鼠标靠近时稍稍凑近。持续移动鼠标时暂缓随机待机动作，停下后仍保持注视。详见 [1.6 更新说明](docs/1.6-更新说明.md)。

奶油小猫或云朵大白狗，轻轻提醒喝水、起身活动，也替你带来偶尔出现的情话。首版为 Windows 10 / 11 x64 桌面应用，核心功能完全离线，无账号、无后端。

## 直接使用

你运行 `release/Banban-Setup-1.6.0.exe` 安装制作端。她只需要你从“送给她”生成的独立桌宠 EXE。也可以在完整的 `release/win-unpacked` 目录中运行制作端 `伴伴.exe`，不要只复制其中一个 exe。

首次打开，在“伴伴的家”点击“开始陪伴”。提醒默认喝水 60 分钟、活动 90 分钟，每天在 09:00–12:00 和 14:00–18:00 生效；进入有效时段后再经过一个完整间隔才提醒。

- 拖动桌宠移动位置，单击互动，右键打开菜单。
- 通过设置或托盘暂停、隐藏、恢复、退出。
- 双击托盘图标找回桌宠。
- “桌宠模样”中选择奶油小猫或云朵大白狗，点击“摸摸试试看”预览回应。
- “专属心意”中填写称呼、欢迎语，新增自己的情话；修改自动保存。
- 在“送给她”中制作独立桌宠 EXE，把这一个文件交给她。旧版 JSON 导入 / 导出接口保留用于制作端内容迁移。
- 系统全屏时自动避让；会议或屏幕共享前，建议使用手动暂停。

完整说明见 [使用说明.md](docs/使用说明.md)，测试范围和已知限制见 [验收记录.md](docs/验收记录.md)。

## 已实现

- 原创 SVG 小猫和大白狗，眼、头、脸部和身体分层跟随鼠标，近距离轻轻凑近；随机歪头、抬爪、伸懒腰、甩尾巴，自然呼吸和眨眼；摸摸、喝水与爱心反馈。
- 透明窗口与按可见图形响应鼠标、可拖动、位置保存、三档尺寸、置顶控制、托盘菜单。
- 喝水 / 活动提醒；完成、跳过、仅一次延后；同时到期合并；自动气泡至少间隔 10 分钟。
- 两段每日有效时段、暂停 30 / 60 分钟或至明天、锁屏与休眠恢复、真实全屏检测。
- 36 条内置情话、自定义文案、单条编辑与停用、完整小池轮换与最近 10 条去重。
- 自动情话随机间隔 120–180 分钟、每日最多 2 次，主动索取不受此限制。
- 首次欢迎、变量替换、礼物包导入预览与导出、恢复默认、清除个人内容。
- 本地校验、原子保存、有效备份恢复、单实例、开机启动选项。
- Windows 安装包、卸载时可选择清除数据。

## 开发

需要 Node.js 22+、npm，以及 Windows 自带的 .NET Framework 4.x 编译器（用于构建轻量全屏检测组件）。

仓库包含源码、素材和测试。依赖、测试数据及安装包不随源码提交；克隆后先执行下面的准备步骤，再运行 `npm run build` 生成安装包。

```powershell
npm ci
npm run assets
npm start
```

```powershell
npm test
npm run test:ui
npm run test:native
npm run test:surprise
npm run test:moments
npm run test:motion
npm run test:gaze-live
npm run build
```

`test:ui` 与 `test:native` 会打开独立测试实例，数据存放在 `test-results`，不会改动正式应用配置。`scripts/installed-smoke.cjs` 用于验证安装在 `%LOCALAPPDATA%\Programs\Banban` 的正式构建。

构建采用 Electron + 原生 HTML/CSS/JavaScript，无前端构建服务。`sharp` 仅在构建图标时使用，Playwright 仅用于测试；安装包不包含这些开发依赖。

默认 `npm run build` 输出到 `release`；打包版动作测试可用 `BANBAN_PACKAGED_DIR` 指定解压目录，再运行 `npm run test:motion -- --packaged`。`test:gaze-live` 使用真实系统鼠标坐标与动画偏好，测试时会移动独立测试桌宠窗口。

## 代码结构

```text
src/main.cjs              窗口、托盘、系统事件、IPC、安装版集成
src/preload.cjs           隔离的有限接口
src/core/config.cjs      默认值、校验、礼物格式
src/core/scheduler.cjs   可独立测试的提醒和情话调度
src/core/store.cjs       原子保存及备份恢复
src/ui/                  桌宠和设置界面
assets/                  原创猫咪、大白狗、应用图标
scripts/FullscreenSensor.cs  全屏边界检测，无标题或进程内容采集
build/installer.nsh      卸载数据选项
tests/                   核心行为测试
docs/                    使用说明与验收记录
```

## 数据与隐私

正式应用配置位于 `%APPDATA%\Banban`。核心文件为 `settings.json`、`runtime.json` 及 `.bak` 备份。

不读取屏幕内容，不使用摄像头或麦克风，不记录健康行为完成明细，不向赠送者发送使用状态。全屏组件只判断前台窗口边界，返回是 / 否。日志仅记录固定错误代码，不写入情话正文。

视线跟随仅在桌宠可见且系统允许动画时读取鼠标坐标，坐标不保存；隐藏、锁屏和休眠时停止采样。

应用使用上下文隔离、沙箱、关闭 Node 渲染权限、限制 IPC、禁止新窗口和远程网络请求；所有导入内容按纯文本显示。

“清除专属内容”会更新配置与备份，不会删除用户已经自行导出的礼物文件。安装包目前未做商业代码签名。
